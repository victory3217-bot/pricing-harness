# 가격 진단 계산기 · 입력 정리 시트 수강생 안내

수업을 들은 분들을 위한 안내입니다. 이 계산기는 **스타트업 상품기획에 특화된 가격 관리 도구**입니다. 그래서 "변동비"의 뜻이 회계 일반론(생산량에 따라 늘어나는 모든 비용)과 다릅니다. 아래 "비용을 넣는 곳"을 먼저 읽어 주세요.

## 준비물

- 웹 계산기: <https://victory3217-bot.github.io/pricing-harness/calculator/> (설치·가입 불필요, 영어는 `?lang=en`)
- 입력 정리 시트: [**⬇ Pricing_Input_Worksheet.xlsx 내려받기**](https://victory3217-bot.github.io/pricing-harness/calculator/Pricing_Input_Worksheet.xlsx) (계산기 위쪽의 **"⬇ 입력 정리 시트 받기"** 버튼으로도 받을 수 있습니다). Excel이나 구글 스프레드시트(업로드해서 열기)에서 쓸 수 있습니다.

## 내 데이터는 어디에 저장되나요?

- 시트는 **비어 있는 양식**이고, 입력한 내용은 **내 컴퓨터에만** 저장됩니다.
- 계산기는 브라우저 안에서만 계산하며 입력값을 어디로도 보내지 않습니다. 강사에게도 전달되지 않습니다.
- 계산기는 입력값을 저장하지 않습니다. 창을 닫으면 사라지니, 정리한 값은 시트에 남겨 두세요.

## 사용 순서

1. **시트의 `초도` 탭**에서 처음 만드는 물량(초도생산)의 비용을 정리합니다.
2. 초도물량으로 본전이 되는지, 소진기간 안에 얼마나 팔아야 하는지 **판정**을 읽습니다.
3. 규모를 키울 계획이 있으면 **`양산` 탭**을 채우고 **`비교` 탭**에서 차이를 봅니다.
4. 시트 아래쪽 **"계산기에 입력할 값"** 표(라벨과 값 두 열)를 복사해, 웹 계산기 왼쪽 위 **"시트 값 붙여넣기"** 칸에 붙여넣고 **"붙여넣은 값으로 채우기"** 를 누릅니다 (직접 옮겨 적어도 됩니다). 붙여넣은 내용은 브라우저 안에서만 읽습니다. 기존 입력값은 바뀝니다. 그다음 목표 공헌이익률·할인율·시장가격은 계산기에서 정해 검토합니다.

계산기는 값을 입력하면 결과가 **자동으로 계산됩니다** (계산 버튼이 없습니다).

## 비용을 넣는 곳

| 비용 | 예 | 넣는 곳 |
| --- | --- | --- |
| 만드는 데 드는 비용 | 재료비, 가공비, 외주 제작비, 금형·장치, 개발 인건비 | 시트 `초도` 2번 (총비용). 계산기에서는 **직접원가**(1개당 금액) |
| 팔 때마다 붙는 비용 | 판매 수수료, 결제수수료, 배송비, 건당 광고비 | 시트 `초도` 3번 `판매 시 …`. 계산기에서는 **변동비** |
| 팔기 전에 한 번 쓰는 비용 | 입점비, 샘플, 초기 마케팅 | 시트 `초도` 3번 `런칭 전 총액` |
| 물량과 무관하게 매달 나가는 비용 | 임대료, 상시 인건비, 구독·툴 비용 | 시트 `초도` 3-2번 (월 고정운영비) |

주의할 점:

- **계산기의 직접원가는 총액이 아니라 판매 단위 1개당 금액**입니다. 개발비 전체 같은 총액을 그대로 넣으면 결과가 크게 왜곡됩니다. 시트가 총비용 ÷ 수량으로 환산해 줍니다.
- **변동비에는 판매·배송 비용만** 넣습니다. 제작 관련 비용은 직접원가에 넣으세요.
- 같은 비용을 두 곳에 넣으면 **두 번 차감**됩니다.
- 정액은 총액이 아니라 **판매 단위 1개당 금액**, %는 퍼센트 숫자(예: 10)로 적습니다.

## 판매 단위를 먼저 정하세요

시트 `초도` 탭의 "판매 단위"에 한 번 팔 때의 단위를 적습니다 (예: 낱개 1개, 6개입 세트, 1건). **판매가, 수량, 모든 비용이 이 단위를 기준**으로 합니다.

- 판매 단위가 낱개 1개이면 금액은 낱개당, 6개입 세트이면 세트당, 주문 1건이면 주문당입니다. 판매 단위가 주문 1건이면 주문당 택배비가 그대로 판매 단위당 비용입니다.
- 단위가 다르면 환산해서 적으세요 (낱개 원가가 1,000원인 6개입 세트는 6,000원).
- 낱개와 묶음을 모두 판다면 주력 판매 단위로 한 번, 다른 단위로 한 번 따로 정리하세요.

## 시트의 탭

- **초도:** 처음 만드는 물량 기준. 활동별 총비용만 적고(구분 없음), 판정을 봅니다.
- **양산:** 규모를 키워 다시 만들 때 기준. 반복 비용, 새 투자, 바뀌는 판매·고정비를 적습니다. 값은 견적서나 근거 있는 가정으로 채워 주세요.
- **비교:** 초도와 양산을 같은 정의로 나란히 보여줍니다 (입력 없음).
- **사용법:** 시트 안의 상세 안내입니다.

노란 칸만 입력하고, 회색 칸은 자동 계산입니다.

## 결과를 읽는 법

- **본전에 필요한 누적 판매량 ÷ 수량이 100%를 넘으면** 초도물량을 모두 팔아도 본전이 안 됩니다. 가격, 비용, 고정비, 기간을 다시 검토하세요.
- **본전 판매가**는 초도물량을 소진기간 안에 모두 팔았을 때 손익이 0이 되는 가격입니다.
- **판매 단위당 공헌이익이 0 이하**이면 팔수록 손해입니다.
- 시트의 판정은 **간이 판단**입니다. 재고·외상 같은 시차와 추가 생산은 반영하지 않으며, 세법상 감가상각과 다를 수 있습니다. 정식 계산은 웹 계산기에서 하세요.
- 계산기에 넣는 판매 단위당 직접원가(초도 완전원가)는 시트와 근사치로만 같습니다.

## 자주 막히는 곳

- **합계가 0이에요:** 3번 표에서 `구분`을 고르지 않은 행은 합계에 들어가지 않습니다. 표 아래 "구분을 고르지 않은 행 수"를 확인하세요.
- **"필수 입력을 채워 주세요"가 나와요:** 판매가, 부가세율, VAT 포함 여부, 수량, 소진기간을 모두 입력하세요.
- **행이 모자라요:** 표 아래에 적지 말고 중간 줄 위에 행을 삽입하세요 (표 아래에 적은 줄은 합계에서 빠집니다).
- **구글 스프레드시트에서 열면 이상해요:** 업로드해서 열어야 하며, 드롭다운·서식은 확인되지 않았습니다. 문제가 있으면 Excel로 열어 보세요.

이 도구는 학습용 간이 계산기이며, 실제 의사결정에는 별도의 검토를 병행하세요.
